═══════════════════════════════════════════════════════════════
  🧪 CÓMO PROBAR
═══════════════════════════════════════════════════════════════

1. Abrir: http://localhost:8000
2. Comenzar exploración
3. Probar movimientos:
   - WASD: Observar si los pies se deslizan
   - Shift + WASD: Verificar que sea más rápido
   - Espacio: Verificar altura de salto

4. Si necesitas ajustar:
   - Abrir consola (F12)
   - Probar valores:
     player.speed = 0.10;  // Más rápido
     player.speed = 0.06;  // Más lento
