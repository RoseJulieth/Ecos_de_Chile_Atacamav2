═══════════════════════════════════════════════════════════════════
                    🎮 CÓMO USAR LAS NUEVAS CARACTERÍSTICAS
═══════════════════════════════════════════════════════════════════

RECOLECTAR FRAGMENTOS:
   1. Acércate a un fragmento (brilla y flota)
   2. Verás el texto "E: Recolectar"
   3. Presiona E para recolectar
   4. Lee la información educativa

HABLAR CON NPCs:
   1. Busca NPCs con iconos flotantes
   2. Acércate hasta ver "E: Hablar"
   3. Presiona E para iniciar conversación
   4. Lee la cuña histórica
   5. Presiona E o ESC para cerrar

MOVIMIENTO:
   • Usa WASD o Flechas (ambos funcionan)
   • Mantén Shift para correr
   • Presiona Espacio para saltar
   • El personaje rota suavemente
