═══════════════════════════════════════════════════════════════

PASO 1: PRUEBA AISLADA DEL MODELO
──────────────────────────────────

1. Abre tu navegador
2. Ve a: http://localhost:8000/test_male_casual.html
3. Espera a que cargue el modelo
4. Verifica:
   ✓ Modelo visible en el centro
   ✓ Lista de animaciones a la derecha
   ✓ Click en cada animación para verla

5. Si el modelo es muy grande o pequeño:
   - Click en "Escala ×2" o "Escala ÷2"
   - Encuentra el tamaño correcto
   - Anota la escala (aparece en pantalla)

6. Si el modelo mira hacia atrás:
   - Click en "↻ 180°"


PASO 2: PRUEBA EN EL JUEGO
───────────────────────────

1. Abre tu navegador
2. Ve a: http://localhost:8000
3. Presiona F12 para abrir la consola
4. Click en "Comenzar Exploración"
5. Click en la pantalla para capturar el mouse

6. Busca la ESFERA ROJA (marca donde está el jugador)
   - Si la ves, el sistema funciona ✓
   - Si no la ves, revisa la consola

7. Prueba los controles:
   - W o ↑ : Adelante
   - S o ↓ : Atrás
   - A o ← : Izquierda
   - D o → : Derecha
   - Shift : Correr (mantener mientras te mueves)
   - Espacio: Saltar

8. Verifica las animaciones:
   - Quieto = Idle (reposo)
   - Moverse = Walk (caminar)
   - Shift + Moverse = Run (correr)
   - Espacio = Jump (saltar)

SI VES LA ESFERA ROJA PERO NO EL MODELO:

El modelo está cargado pero la escala es incorrecta.

SOLUCIÓN:
1. Usa test_male_casual.html para encontrar la escala correcta
2. Abre: index.html
3. Busca la línea 390 aproximadamente:
   player.mesh.scale.set(0.01, 0.01, 0.01);
4. Cambia los valores según lo que encontraste
5. Guarda y recarga el juego (F5)

VALORES COMUNES:
- 0.001 = Muy pequeño
- 0.01  = Pequeño (Mixamo) ← ACTUAL
- 0.1   = Mediano
- 1     = Grande
- 10    = Muy grande
