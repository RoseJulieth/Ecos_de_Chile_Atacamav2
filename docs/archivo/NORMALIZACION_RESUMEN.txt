═══════════════════════════════════════════════════════════════
  CÓMO FUNCIONA LA NORMALIZACIÓN AUTOMÁTICA
═══════════════════════════════════════════════════════════════

1. Aplicar escala inicial al modelo (aproximada)
2. Calcular bounding box real del modelo
3. Calcular altura actual con esa escala
4. Calcular nueva escala: (1.7 / altura_actual) * escala_inicial
5. Aplicar escala normalizada
6. Resultado: Modelo mide exactamente 1.7 unidades ✅
