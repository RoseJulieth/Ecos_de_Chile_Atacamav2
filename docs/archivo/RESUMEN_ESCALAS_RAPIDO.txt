🎯 PROBLEMA:
   Personajes microscópicos (0.34 unidades) en terreno 200x200

✅ SOLUCIÓN:
   Aumentar escala de personajes 5x → altura realista 1.7 unidades

═══════════════════════════════════════════════════════════════
  CAMBIOS APLICADOS
═══════════════════════════════════════════════════════════════

📦 JUGADOR (index.html línea ~591)
   ANTES: scale.set(0.02, 0.02, 0.02)  → ~0.34 unidades
   AHORA: scale.set(0.1, 0.1, 0.1)     → ~1.7 unidades ✅

👥 NPCs GLB (js/NPCManager.js línea ~18-63)
   ANTES: scale: 0.5   → ~0.4 unidades
   AHORA: scale: 2.5   → ~1.7 unidades ✅

👥 NPCs FBX (js/NPCManager.js línea ~48)
   ANTES: scale: 0.025 → ~0.42 unidades
   AHORA: scale: 0.12  → ~1.7 unidades ✅

🏃 VELOCIDADES (js/Player.js línea ~20-22)
   ANTES: speed: 0.08, jumpForce: 0.30
   AHORA: speed: 0.4,  jumpForce: 1.5  (5x) ✅

📡 RAYCASTER (js/Player.js línea ~32-33)
   ANTES: far: 1.5, distance < 2.0
   AHORA: far: 3.0, distance < 3.5  (2x) ✅

🤝 INTERACCIÓN (js/NPCManager.js línea ~365)
   ANTES: distance < 3.0
   AHORA: distance < 5.0  (1.67x) ✅

═══════════════════════════════════════════════════════════════
  CÓMO PROBAR
═══════════════════════════════════════════════════════════════

1. Recarga el navegador (F5)
2. Verifica que el jugador se vea MUCHO más grande
3. Acércate a un NPC - deben tener altura similar
4. Camina y corre - debe sentirse más rápido
5. Salta - debe verse más alto
