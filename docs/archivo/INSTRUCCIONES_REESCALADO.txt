  PASOS PARA VERIFICAR
═══════════════════════════════════════════════════════════════

1. RECARGAR EL NAVEGADOR
   → Presiona Ctrl + F5 (recarga forzada)
   → O cierra y abre: http://localhost:8000

2. ABRIR CONSOLA
   → Presiona F12
   → Ve a la pestaña "Console"

3. INICIAR EL JUEGO
   → Click en "Comenzar Exploración"
   → Click en la pantalla para capturar el mouse

4. BUSCAR ESFERAS
   → 🟢 VERDE = Tú (el jugador)
   → 🔴 ROJAS = NPCs (busca alrededor)

═══════════════════════════════════════════════════════════════
  SI NO VES LOS MODELOS (SOLO ESFERAS)
═══════════════════════════════════════════════════════════════

Posibles causas:

1. Los archivos GLB/FBX no se cargaron correctamente
   → Revisa la consola para errores
   → Verifica que existen:
     - assets/models/player/Male_Casual.fbx
     - assets/models/npcs/Character.glb
     - assets/models/npcs/Animated_Woman.glb

2. Los modelos necesitan otra escala
   → Si son muy grandes: cambiar a 0.5
   → Si son muy pequeños: cambiar a 1.5

3. Los modelos tienen problemas de textura
   → Las esferas indican que la posición es correcta
   → El problema es solo visual
