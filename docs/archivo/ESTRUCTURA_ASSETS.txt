═══════════════════════════════════════════════════════════════════
                    📏 ESPECIFICACIONES TÉCNICAS
═══════════════════════════════════════════════════════════════════

MODELOS 3D:
   Formato:     GLTF/GLB (recomendado)
   Polígonos:   1,000 - 5,000 (low-poly)
   Escala:      1 unidad = 1 metro
   Orientación: Mirando hacia +Z
   Tamaño:      < 5MB por archivo

TEXTURAS:
   Formato:     JPG (opaco) o PNG (transparente)
   Tamaño:      512x512, 1024x1024, 2048x2048
   Tileable:    Sí (sin costuras)
   Compresión:  80-90% calidad
   Tamaño:      < 2MB por archivo

═══════════════════════════════════════════════════════════════════
                    🚀 INICIO RÁPIDO
═══════════════════════════════════════════════════════════════════

1. LEE LA DOCUMENTACIÓN
   → GUIA_ASSETS.md (guía completa)
   → assets/README.md (resumen)
   → Carpetas individuales (detalles)

2. DESCARGA RECURSOS
   → Mixamo para el jugador
   → Poly Haven para texturas
   → Sketchfab para referencias

3. PREPARA EN BLENDER
   → Importa/modela
   → Ajusta escala
   → Exporta como GLTF

4. COLOCA ARCHIVOS
   → Copia a las carpetas correctas
   → Sigue los nombres de archivo

5. PRUEBA EN EL JUEGO
   → Abre el navegador
   → Verifica la consola (F12)
   → Busca mensajes de carga


═══════════════════════════════════════════════════════════════════
                    💡 CONSEJOS IMPORTANTES
═══════════════════════════════════════════════════════════════════

1. NO TE ABRUMES
   → Empieza con lo básico
   → Agrega assets gradualmente
   → Los placeholders funcionan bien

2. MANTÉN LA SIMPLICIDAD
   → Estilo low-poly
   → Colores planos
   → Menos es más

3. PRUEBA FRECUENTEMENTE
   → Carga un asset a la vez
   → Verifica que funciona
   → Luego continúa

4. USA LA CONSOLA
   → F12 en el navegador
   → Busca mensajes de error
   → Verifica que los assets cargan
