## 🚀 Cómo Usar el Sistema

### Para Jugadores
1. **Acercarse a un NPC** con video (Don Pedro, Capitán Vargas, etc.)
2. **Presionar 'E'** para iniciar diálogo
3. **Ver el contenido**: Leer texto y reproducir video embebido
4. **Opciones adicionales**:
   - Botón "🎬 Ver en YouTube" para pantalla completa
   - Botón "Cerrar (E)" para salir del diálogo

### Para Desarrolladores
1. **Agregar video a NPC**: Añadir campo `youtube_video` en `npcDialogs.json`
2. **Formato flexible**: Cualquier URL de YouTube es compatible
3. **Automático**: El sistema maneja conversión y visualización
