═══════════════════════════════════════════════════════════════════
                    🚀 PASOS RÁPIDOS
═══════════════════════════════════════════════════════════════════

1. OBTENER MODELOS
   ─────────────────────────────────────────────────────────────
   Opción A: Descargar de Mixamo (gratis)
   → mixamo.com
   → Busca "Character"
   → Descarga con animaciones

   Opción B: Modelar en Blender
   → Crea tu propio personaje
   → Exporta como GLTF

   Opción C: Usar modelos gratuitos
   → sketchfab.com
   → poly.pizza
   → Busca "low poly character"


2. PREPARAR EN BLENDER
   ─────────────────────────────────────────────────────────────
   • Escala correcta (jugador = 1.8 unidades)
   • Orientación: Mirando hacia +Z
   • Aplicar transformaciones (Ctrl+A)
   • Exportar como GLTF 2.0 (.glb)


3. COLOCAR ARCHIVOS
   ─────────────────────────────────────────────────────────────
   Copia tus archivos .glb a las carpetas correspondientes:

   player/player.glb
   npcs/miner/miner.glb
   fragments/jarro_pato.glb


4. ACTUALIZAR CÓDIGO (Opcional)
   ─────────────────────────────────────────────────────────────
   El código ya está preparado para cargar los modelos.
   Solo necesitas seguir los nombres de archivo correctos.

   Ver: GUIA_ASSETS.md para detalles

                    ⚙️ CONFIGURACIÓN DE EXPORTACIÓN
═══════════════════════════════════════════════════════════════════

En Blender:
   Archivo → Exportar → glTF 2.0 (.glb)

═══════════════════════════════════════════════════════════════════
                    ✅ VERIFICACIÓN
═══════════════════════════════════════════════════════════════════

Después de colocar los archivos:

1. Abre el juego en el navegador
2. Abre la consola (F12)
3. Busca mensajes:
   ✅ "Modelo cargado: player"
   ✅ "Modelo cargado: npc_miner"
   ✅ "Modelo cargado: fragment_diaguita"

4. Si ves ⚠️ "Usando placeholder":
   → El modelo no se encontró
   → Verifica la ruta del archivo
   → Verifica el nombre del archivo


═══════════════════════════════════════════════════════════════════
                    🎨 RECOMENDACIONES
═══════════════════════════════════════════════════════════════════

ESTILO:
   • Low-poly (1000-5000 polígonos)
   • Colores planos o texturas simples
   • Estilo cel-shading (cartoon)

TAMAÑO:
   • Jugador: 1.8 unidades de altura
   • NPCs: 1.6-1.9 unidades
   • Fragmentos: 0.5-0.8 unidades

ANIMACIONES (solo jugador):
   • idle (reposo)
   • walk (caminar)
   • run (correr)
   • jump (saltar)
